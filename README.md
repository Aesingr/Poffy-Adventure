# Poffy Adventure

Audiogame per giocatori non vedenti e ipovedenti: si gioca interamente ad ascolto, con la sintesi vocale del browser.

An audiogame for blind and visually impaired players: it is played entirely by ear, using the browser's speech synthesis.

## Gioca / Play

- Italiano: [Poffy adventure](https://aesingr.github.io/Poffy-Adventure/Poffy%20adventure.html) · [Cabinato online](https://aesingr.github.io/Poffy-Adventure/Cabinato%20online.html)
- English: [Poffy adventure](https://aesingr.github.io/Poffy-Adventure/Poffy%20adventure%20EN.html) · [Poffy Arcade online](https://aesingr.github.io/Poffy-Adventure/Cabinato%20online%20EN.html)

Funziona nei browser recenti (Chrome, Edge, Firefox) su computer, con tastiera.
Works in recent desktop browsers (Chrome, Edge, Firefox), keyboard required.
